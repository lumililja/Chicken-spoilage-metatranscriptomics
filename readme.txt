Chicken HUMAnN Pathway Plot Pipeline
====================================

This folder contains standalone Python scripts for preparing species profiles,
building KO reaction tables, and producing pathway plots. The 4 C and 6 C
pathway workflows are selected using a temperature parameter.


Requirements
------------

Python packages:

- pandas
- matplotlib

External commands required to build the reaction CSV files:

- humann
- humann_regroup_table

Activate the environment containing HUMAnN before running the builder.

The file utility_mapping/map_ko-expanded_uniref90.txt.gz is also required by
build_ko_all_reactions.py. It must be added locally after cloning because its
size exceeds GitHub's standard 100 MB per-file limit.

The scripts expect the existing input folders and mapping files to remain in
this workspace, including:

- bracken_outputs_6/
- humann_output_4_degrees/
- humann_output_6_degrees/
- utility_mapping/


Upstream Processing Files
-------------------------

Processing_and_species_composition.txt documents the upstream processing used
to obtain the Bracken species-composition files. It contains command examples
for removing rRNA reads, removing chicken reads, running Kraken2 and Bracken,
and generating Krona visualizations for the 4 C and 6 C datasets. The commands
include Puhti-specific paths and should be adapted before reuse.

humann_script.sh is a Puhti SLURM batch script for running HUMAnN on processed
FASTQ files. It uses the MetaPhlAn-style profiles generated by
found_species_analysis.py, the ChocoPhlAn nucleotide database, and the HUMAnN
module available on Puhti. Its HUMAnN outputs provide the gene-family tables
used by build_ko_all_reactions.py.


Prepare Species Profiles
------------------------

To convert Bracken output into MetaPhlAn-style profiles and report which
identified species are available in ChocoPhlAn:

    python3 found_species_analysis.py

The script writes profiles to bracken_to_metaphlan/. Its input, output,
ChocoPhlAn database path, and minimum abundance threshold are configured near
the top of found_species_analysis.py.


Step 1: Build the KO reaction CSV
---------------------------------

For the 4 C experiment:

    python3 build_ko_all_reactions.py --temperature 4

For the 6 C experiment:

    python3 build_ko_all_reactions.py --temperature 6

These commands:

1. Regroup HUMAnN gene-family tables to KO identifiers.
2. Run HUMAnN using utility_mapping/ko_pathway_modules.txt.
3. Clean and merge stratified reaction abundance tables.
4. Add reaction, bacterium, name, and pathway-class columns.

The final outputs are:

- ko_all_reactions_4.csv
- ko_all_reactions_6.csv

Intermediate outputs are written to:

- KO_4/ or KO_6/
- humann_rebuild_4/ or humann_rebuild_6/
- KO_reactions_pathabundances_4/ or KO_reactions_pathabundances_6/

Step 2: Produce the Final Pathway Plots
--------------------------------------

After generating the corresponding ko_all_reactions CSV file, run:

    python3 pathway_box_plots.py --temperature 4

or:

    python3 pathway_box_plots.py --temperature 6

The generated image is:

- 4_deg_bar_plots.png
- 6_deg_bar_plots.png

Using the Scripts from Python
-----------------------------

The functions can also be called from a Python session:

    from build_ko_all_reactions import build_ko_all_reactions
    from pathway_box_plots import create_pathway_figure

    build_ko_all_reactions(4)
    create_pathway_figure(4)


Notes
-----

The final a)-d) figures are stacked pathway-abundance bar plots.

The plotting script accounts for differences between the 4 C and 6 C
datasets. The 4 C analysis uses samples A01-A30 and estimates A02 as the
average of A01 and A03. The 6 C analysis uses samples A05-A19. Each
temperature has its own sample groupings for acceptable, early spoiled, and
late spoiled products. At 6 C, the Carn. maltaromaticum panel shows only the
acceptable stage (Day 7).
